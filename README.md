# gomon

**gomon** — системный монитор и CLI-утилита на Go для просмотра состояния компьютера и управления процессами прямо из терминала.

Проект сочетает обычный **CLI-интерфейс** и интерактивный **TUI** в стиле `htop` / `btop`.

## Возможности

### TUI

При запуске `gomon` без аргументов открывается интерактивный системный монитор.

В интерфейсе доступны:

* текущая загрузка CPU;
* загрузка каждого CPU core;
* использование RAM;
* использование Swap;
* список процессов;
* сортировка процессов;
* навигация по процессам;
* завершение выбранного процесса;
* подтверждение перед завершением процесса;
* автоматическое обновление данных;
* справка по горячим клавишам;
* компактный статус-бар.

### CLI

Для получения информации без запуска TUI доступны отдельные команды:

| Команда            | Описание                                     |
| ------------------ | -------------------------------------------- |
| `gomon`            | Запустить интерактивный TUI                  |
| `gomon cpu`        | Показать загрузку CPU                        |
| `gomon mem`        | Показать использование RAM и Swap            |
| `gomon top`        | Показать процессы с наибольшей загрузкой CPU |
| `gomon kill <pid>` | Завершить процесс                            |
| `gomon version`    | Показать версию программы                    |

## Пример CLI

### CPU

```bash
gomon cpu
```

Пример вывода:

```text
CPU: 12.4%  (8 cores)
Model: AMD Ryzen 7 5800H

  Core 0: 10.2%
  Core 1: 14.8%
  Core 2: 8.1%
  Core 3: 17.3%
```

### Memory

```bash
gomon mem
```

Пример:

```text
Memory: 8.2 GB / 16.0 GB (51.3%)
Swap:   0 B / 4.0 GB (0.0%)
```

### Processes

```bash
gomon top
```

По умолчанию отображается 10 процессов.

Количество можно изменить:

```bash
gomon top -n 20
```

### Завершение процесса

```bash
gomon kill 1234
```

где `1234` — PID процесса.

### Версия

```bash
gomon version
```

## Управление

### Навигация

| Клавиша | Действие            |
| ------- | ------------------- |
| `↑`     | Переместиться вверх |
| `↓`     | Переместиться вниз  |
| `j`     | Переместиться вниз  |
| `PgUp`  | Страница вверх      |
| `PgDn`  | Страница вниз       |

### Сортировка

| Клавиша | Сортировка              |
| ------- | ----------------------- |
| `c`     | По загрузке CPU         |
| `m`     | По использованию памяти |
| `p`     | По PID                  |
| `n`     | По имени процесса       |

### Управление процессами

| Клавиша   | Действие                    |
| --------- | --------------------------- |
| `k` / `K` | Завершить выбранный процесс |
| `y`       | Подтвердить завершение      |
| `n`       | Отменить завершение         |

Перед завершением процесса программа показывает подтверждение.

### Прочее

| Клавиша  | Действие                      |
| -------- | ----------------------------- |
| `r`      | Принудительно обновить данные |
| `?`      | Открыть справку               |
| `q`      | Выйти                         |
| `Esc`    | Выйти / закрыть окно          |
| `Ctrl+C` | Выйти                         |

# Установка

## Требования

* Go 1.24+
* терминал с поддержкой ANSI escape sequences

Проект использует:

* [Bubble Tea](https://github.com/charmbracelet/bubbletea) — TUI framework
* [Lip Gloss](https://github.com/charmbracelet/lipgloss) — оформление терминального интерфейса
* [Cobra](https://github.com/spf13/cobra) — CLI
* [gopsutil](https://github.com/shirou/gopsutil) — получение системной информации

## Сборка из исходников

Клонировать репозиторий:

```bash
git clone https://github.com/kab4nsunrise/gomon.git
cd gomon
```

Установить зависимости:

```bash
go mod tidy
```

Собрать программу:

```bash
go build -o gomon ./cmd/gomon
```

После сборки запустить:

```bash
./gomon
```

В Windows:

```powershell
go build -o gomon.exe ./cmd/gomon
```

Запуск:

```powershell
.\gomon.exe
```

# Конфигурация

По умолчанию программа использует:

| Параметр                          | Значение |
| --------------------------------- | -------: |
| Интервал обновления               |     `1s` |
| Максимальное количество процессов |     `50` |
| Тема                              |   `dark` |

Интервал обновления можно изменить:

```bash
gomon --interval 2s
```

Количество отображаемых процессов:

```bash
gomon --limit 100
```

Параметры можно комбинировать:

```bash
gomon --interval 2s --limit 100
```

### `cmd/gomon`

Точка входа приложения.

Здесь находится:

* настройка Cobra;
* CLI-команды;
* запуск TUI;
* глобальные параметры приложения.

### `internal/sysinfo`

Слой получения информации о системе.

Используется библиотека `gopsutil`.

Реализовано получение:

* CPU;
* RAM;
* Swap;
* дисков;
* сетевой статистики;
* списка процессов;
* информации о процессах;
* PID и имени процесса;
* CPU/MEM usage;
* пользователя;
* статуса;
* RSS;
* командной строки.

Также реализовано завершение процесса по PID.

### `internal/tui`

Интерактивный интерфейс построен по модели **Elm Architecture**, используемой Bubble Tea:

```text
Input
  ↓
Update
  ↓
Model
  ↓
View
  ↓
Terminal
```

Данные системы периодически запрашиваются асинхронно и передаются в TUI через сообщения Bubble Tea.

### `internal/tui/components`

Отдельные компоненты интерфейса:

* CPU panel;
* Memory panel;
* Processes table;
* Status bar;
* Confirmation dialog;
* Help screen.

### `internal/tui/styles`

Централизованное оформление интерфейса с использованием Lip Gloss:

* панели;
* заголовки;
* строки таблицы;
* progress bars;
* предупреждения;
* сообщения об ошибках;
* confirmation dialog.

# Что демонстрирует проект

Проект предназначен не только для мониторинга системы, но и как практический пример разработки CLI/TUI-приложения на Go.

В нём используются:

* работа с операционной системой;
* получение системных метрик;
* работа с процессами;
* управление процессами;
* CLI-дизайн;
* интерактивный терминальный интерфейс;
* обработка пользовательского ввода;
* асинхронные операции;
* периодическое обновление данных;
* структурирование Go-проекта;
* работа с внешними библиотеками;
* кросс-компиляция;
* Makefile automation.
